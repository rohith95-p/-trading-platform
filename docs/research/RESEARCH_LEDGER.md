# Research Ledger

Every hypothesis this project has tested, what was actually measured, and the
verdict. The point of this file is that no one re-runs a settled question or
re-adopts a rejected idea because the reasoning was never written down.

**Rules for this file**

- One row per hypothesis, with an ID that never gets reused.
- A verdict must cite a run directory under `research/runs/` or it is not a verdict.
- "Insufficient evidence" is a valid, common, and honest outcome. It is not a
  polite way of saying "probably fine".
- If a result is later contradicted, do not edit the old row. Add a new one and
  link back. The history of what we believed is part of the evidence.
