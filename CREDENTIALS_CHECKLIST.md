## 🔑 Credentials by Priority

### ✅ REQUIRED NOW (Task 6.1 - Railway Deployment)

#### 1. JWT Secret (Generate)
**Purpose**: User authentication tokens  
**How to get**: Generate with command below  
**Where to use**: Railway environment variables

```powershell
# PowerShell command to generate
$bytes = New-Object byte[] 32
[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
[Convert]::ToBase64String($bytes)
```

#### 2. Encryption Key (Generate)
**Purpose**: Encrypt API keys in database  
**How to get**: Generate with command below  
**Where to use**: Railway environment variables

```powershell
# PowerShell command to generate
-join ((1..32) | ForEach-Object { '{0:x2}' -f (Get-Random -Minimum 0 -Maximum 256) })
```

#### 3. Database URL (Auto-generated)
**Purpose**: PostgreSQL connection  
**How to get**: Railway auto-generates when you add PostgreSQL  
**Where to use**: Railway environment variables (automatic)

```bash
railway add --plugin postgresql
# DATABASE_URL is automatically set
```

#### 4. Redis URL (Auto-generated)
**Purpose**: Caching and real-time data  
**How to get**: Railway auto-generates when you add Redis  
**Where to use**: Railway environment variables (automatic)

```bash
railway add --plugin redis
# REDIS_URL is automatically set
```
