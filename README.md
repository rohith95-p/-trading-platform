# 🦅 Ultra Core - Institutional Trading Workspace

Welcome to the Ultra Core Quantitative Trading Workspace. This environment is designed for institutional-level, autonomous algorithmic trading on MetaTrader 5, specifically tuned for XAUUSD (Gold).

## 📂 Folder Structure

This workspace is strictly organized into logical components to separate strategy generation, core execution, and daily research.

### `docs/`
The brain of the operation. Contains all analysis, plans, and historical logs.
- `plans/`: Contains the dynamic daily files (`DAILY_MARKET_ANALYSIS.md` and `DAILY_BATTLE_PLAN.md`). These are automatically regenerated by the AI when you ask for "tomorrow's plan".
- `research/`: Contains deep, static research documents (e.g., `INSTITUTIONAL_XAUUSD_RESEARCH.md` detailing Smart Money Concepts and macro logic).
- `trade_logs/`: Contains `LIVE_TRADE_HISTORY.md`, a ledger of all live closed deals pulled directly from MT5.

### `src/`
The code layer.
- `core/`: Contains the primary execution engines, most notably `london_bot.py`. This script connects to MT5, manages risk (e.g., MAX 2 open trades), and executes orders.
- `strategies/`: Contains the individual strategy logic modules and indicator math.
- `api/` / `intelligence/`: Supporting application infrastructure.

### `.agents/`
The AI Configuration layer.
- `skills/`: Contains custom, reusable workflows for the AI.
  - `xauusd-trading-prep`: Fetches a 6-asset global macro matrix to generate the Daily Market Analysis and Battle Plan.
  - `mt5-trade-auditor`: Connects to the MT5 MCP to pull closed deals and update the `LIVE_TRADE_HISTORY.md` ledger.
- `rules/`: Contains non-negotiable boundaries, such as `agent_boundaries.md` (which prevents the AI from unilaterally restricting trade directions without user approval).

## 🤖 Daily Routine
1. **At 8:00 AM:** You open the workspace and tell the AI to "Wake up". The AI ensures `london_bot.py` is running as a background daemon.
2. **During the Day:** The bot autonomously monitors the market, executing trades based on Smart Money Concepts (SMC) and momentum breakouts.
3. **At 11:00 PM:** A cron job automatically triggers the AI to run the `mt5-trade-auditor` skill, update the trade ledger, and scan the bot's logs for errors.
4. **Before Sleep:** You ask the AI for "tomorrow's plan". It fetches live data for Gold, Silver, DXY, 10Y Yields, Oil, and VIX to generate the new Analysis and Battle Plan in `docs/plans/`.
